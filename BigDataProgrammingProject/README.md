# UK Public Transport Big Data Analysis using Apache Spark

## Project Overview

This project analyses UK Bus Open Data Service (BODS) GTFS datasets using Apache Spark and PySpark. The project demonstrates how big data technologies can efficiently process and analyse millions of public transport records to support smart city transport analytics.

## Dataset

The project uses GTFS datasets from the UK Bus Open Data Service (BODS), including:

- Agency
- Routes
- Stops
- Trips
- Stop Times

> Note: The complete GTFS dataset is very large. Some files may not be included in this repository due to GitHub file size limitations.

## Technologies Used

- Python
- Apache Spark
- PySpark
- Pandas
- Matplotlib
- Jupyter Notebook

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest

## Project Features

- Load large GTFS datasets
- Data preprocessing and cleaning
- Feature engineering
- Distributed processing with Apache Spark
- Model training and evaluation
- Data visualisation

## How to Run

1. Install Python.
2. Install Apache Spark.
3. Install the required libraries:

pip install -r requirements.txt

4. Open `UK_Dataset.ipynb` in Jupyter Notebook.
5. Run all cells.
